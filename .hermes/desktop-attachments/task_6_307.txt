# 2. Part 1

Mỗi test có:

```text
5 semantic HTML/CSS text cards
5 questions
3 options mỗi câu
```

Mỗi text:

```text
25–70 từ
```

Giữ nguyên:

```text
renderMode: "html-css"
IDs
question numbering
answer-vault schema
```

Không có:

```text
image
imageUrl
assetId
<img>
```

## Test 14

Dùng 5 ngữ cảnh khác nhau:

```text
community-centre notice
message between neighbours
volunteer email
library update
class booking confirmation
```

## Test 30

Dùng 5 ngữ cảnh khác nhau:

```text
app notification
school technology notice
repair-service message
online-course email
equipment instructions
```

## Test 51

Dùng 5 ngữ cảnh khác nhau:

```text
transport update
hostel notice
eco-tour message
travel booking email
visitor-centre announcement
```

Có thể điều chỉnh tình huống, nhưng ba test phải khác nhau rõ rệt.

## Question skills

Mỗi test phải bao phủ ít nhất 4 kỹ năng:

```text
required action
changed arrangement
purpose
request
important condition
writer intention
```

Không lặp cùng một question stem.

Không tạo 15 câu hỏi theo mẫu:

```text
What should the reader do?
```

## Distractors

Mỗi câu phải có:

* Một đáp án đúng rõ ràng.
* Hai distractor liên quan trực tiếp tới text.
* Distractor sai vì một chi tiết cụ thể.
* Không có option vô lý hoặc khác chủ đề.

# 3. Part 2

Mỗi test có:

```text
5 profiles
8 options A–H
5 unique answers
3 unused distractors
```

## Độ dài

```text
Mỗi profile: 25–45 từ
Mỗi option: 45–75 từ
```

## Matching domains

### Test 14

```text
Local clubs, courses and community activities
```

### Test 30

```text
Technology workshops, learning tools and repair services
```

### Test 51

```text
Trips, outdoor activities and responsible travel
```

Ba test không được dùng chung domain.

## Điều kiện matching

Mỗi profile phải có ít nhất 3 constraints, ví dụ:

```text
available time
experience level
budget
location
equipment
transport
group preference
indoor/outdoor preference
accessibility
desired outcome
```

Option đúng phải thỏa đầy đủ.

Distractor phải thỏa một phần nhưng sai ở ít nhất một điều kiện quan trọng.

Không cho matching bằng một keyword duy nhất.

## Unique answers

Validator phải xác nhận:

```text
5 correct options khác nhau
3 unused options
không profile nào có 2 đáp án ngang nhau
không correct option nào được dùng hai lần
```

# 5. Validator cho Part 1–2

Mở rộng:

```text
scripts/reading/validate-pet-b1-reading-quality-samples.mjs
```

## Part 1 checks

```text
5 cards
5 questions
3 options mỗi câu
25–70 từ mỗi card
0 image references
0 duplicate text
0 duplicate question stem
0 repeated opening phrase dài hơn 8 từ
ít nhất 4 question skills mỗi test
```

## Part 2 checks

```text
5 profiles
8 options
25–45 từ mỗi profile
45–75 từ mỗi option
5 unique answers
3 unused distractors
0 duplicate profile
0 duplicate option
0 repeated opening phrase dài hơn 8 từ
```

## Cross-test similarity

So sánh Test 14, 30, 51 sau khi loại bỏ:

```text
IDs
test numbers
option letters
person names
place names
```

Nếu content vẫn gần giống nhau, validator phải FAIL.

Không dùng AI, embedding hoặc API.
