# 7. Viết lại Part 4

Mỗi Test 20–29 phải có một blueprint Part 4 đầy đủ.

Schema semantic bắt buộc:

{
  paragraphs: [
    {
      segments: [
        { type: "text", value: "..." },
        { type: "gap", questionNumber: 16 },
        { type: "text", value: "..." }
      ]
    }
  ],

  options: [
    {
      key: "q16-correct",
      correctForGap: 16,
      text: "..."
    },
    {
      key: "distractor-1",
      correctForGap: null,
      text: "..."
    }
  ]
}

Không lưu answer theo array position.

Flow:

semantic option
→ deterministic shuffle
→ display label A–H
→ derive answer vault bằng correctForGap

- pronoun reference
- lexical cohesion
- chronology
- contrast
- cause/effect
- paragraph development
- reference tới hành động hoặc ý trước đó
- consequence hoặc reflection

Mỗi sentence đúng phải nối tự nhiên với cả:

- text trước gap
- text sau gap

Ba distractor phải cùng chủ đề nhưng sai rõ bởi:

- reference mismatch
- chronology mismatch
- logical contradiction
- repetition
- wrong paragraph focus

Không tạo distractor vô nghĩa.
