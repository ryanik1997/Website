1. XÁC MINH DEV SERVER PROCESS

Tìm process đang listen port 5173.

Trên Windows, chạy tương đương:

netstat -ano | findstr :5173
Get-Process -Id <PID>

Xác định:

- PID
- command line
- working directory
- Node executable
- thời điểm process khởi động

Bắt buộc chứng minh process chạy từ:

D:\App-English-Ryan\Website\apps\web

hoặc đúng workspace root theo cấu hình thực tế.

Kiểm tra có nhiều process Vite/Node cùng chạy không.

Nếu có:
- dừng toàn bộ process dev server cũ;
- không chỉ đóng terminal hiện tại;
- xác nhận port 5173 đã giải phóng;
- sau đó khởi động lại đúng một process.

5. KIỂM TRA NETWORK CỦA CHÍNH TRÌNH DUYỆT

Trong browser của người dùng:

- mở DevTools → Network;
- bật Disable cache;
- reload;
- tìm request:
  catalog-reading-pet-b1-test30.json
- mở Response;
- copy thứ tự 8 câu;
- ghi Request URL, Status, Remote Address, ETag và Response.

Không dùng một request riêng từ script để thay thế bước này.

Phải xác nhận browser request URL đúng:

http://localhost:5173/catalog/exams/reading/catalog-reading-pet-b1-test30.json
