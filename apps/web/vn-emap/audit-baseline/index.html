      M1 · Materials & Films — dữ liệu vật liệu/màng

      ⚠ OTR của màng nguyên (film) ≠ OTR của bao bì đã đục lỗ (package). Đây là 2 lớp dữ liệu khác nhau: Film OTR + vận chuyển khí qua micro-hole = Effective package gas transfer (model ở phase sau). Trường chưa đo thực nghiệm để null — không tự bịa giá trị.
      Thêm / sửa Film — mở khi cần nhập film mới

      OTR (oxy) — để trống value = null (chưa đo)

      CO₂TR — để trống value = null (chưa đo)

      WVTR (hơi nước) — để trống value = null (chưa đo)
